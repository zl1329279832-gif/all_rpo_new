## 1. 产品概述

太空采矿经营游戏——一款浏览器端即时策略经营游戏，玩家指挥母舰、采矿船、运输船和防卫舰在多个星区之间分配舰队，采集矿物、运输资源、升级基地，并应对陨石灾害、能源短缺和敌对袭扰。目标用户为喜欢策略经营与太空题材的休闲/中度玩家。

## 2. 核心功能

### 2.1 玩家角色
| 角色 | 说明 |
|------|------|
| 舰队指挥官 | 玩家唯一身份，统筹舰队调度、资源管理和科技升级决策 |

### 2.2 功能模块
1. **主界面**：星图总览、舰队状态面板、资源面板、操作按钮区
2. **关卡选择**：展示可用关卡与通关评价
3. **游戏界面**：Canvas 星图渲染、实时飞船移动、事件弹窗、暂停/存档控件
4. **科技面板**：展示可升级科技树与当前等级
5. **结算界面**：关卡目标达成情况、成绩评级

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主界面 | 星图总览 | 以 Canvas 绘制星区节点与航线，展示各星区矿物类型与归属 |
| 主界面 | 舰队状态面板 | 列出当前所有飞船位置、状态、载货 |
| 主界面 | 资源面板 | 展示四类资源当前量/上限、能源消耗速率 |
| 主界面 | 操作按钮区 | 调度飞船、升级科技、暂停/继续、存档/读档 |
| 关卡选择 | 关卡列表 | 展示两张关卡卡片，含星级评价与锁定/解锁状态 |
| 游戏界面 | Canvas 渲染区 | 实时绘制星图、飞船移动、矿物采集动画、战斗特效 |
| 游戏界面 | 事件弹窗 | 陨石灾害、能源危机、敌对袭扰等事件通知与响应选择 |
| 游戏界面 | 暂停/存档控件 | 暂停游戏、手动存档、读取存档 |
| 科技面板 | 科技树 | 展示采矿效率、运输容量、防御力、能源利用率等可升级项 |
| 结算界面 | 成绩评级 | 按资源总量、时间、损失计算 S/A/B/C 评级 |

## 3. 核心流程

玩家选择关卡 → 进入游戏 → 星图随机生成 → 初始母舰与少量飞船部署 → 指派采矿船前往矿物星区采集 → 采矿完成指派运输船运回母舰 → 积累资源升级科技 → 事件随机触发（陨石/能源/敌对） → 玩家决策应对 → 达成关卡目标 → 结算评级

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深空黑(#0a0e1a) + 星云蓝(#1a3a5c) + 矿石金(#d4a847)
- 辅助色：能源绿(#22c55e)、警告红(#ef4444)、界面灰(#374151)
- 按钮：圆角暗色按钮，hover 时亮边发光效果
- 字体：Orbitron（标题/数据）+ Rajdhani（正文/描述）
- 布局：Canvas 星图居中占主区域，左右侧面板展示舰队与资源，底部操作栏
- 图标风格：线条图标，科技感 HUD 风格

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 主界面 | 星图总览 | Canvas 全屏渲染，星区节点为发光圆点，航线为虚线，飞船为小型图标 |
| 主界面 | 舰队状态面板 | 左侧半透明面板，列表展示飞船卡片（图标+名称+状态标签） |
| 主界面 | 资源面板 | 右上角横向排列四类资源条（图标+数量/上限+进度条） |
| 主界面 | 操作按钮区 | 底部工具栏，图标按钮+tooltip |
| 关卡选择 | 关卡列表 | 居中卡片网格，每张卡片含关卡名称、目标简介、星级评价 |
| 游戏界面 | Canvas 渲染区 | 深色背景+星点粒子，飞船平滑移动，采集闪光效果，战斗光束效果 |
| 游戏界面 | 事件弹窗 | 屏幕居中模态框，事件图标+描述+行动按钮 |
| 游戏界面 | 暂停/存档控件 | 右上角图标按钮，暂停时半透明遮罩 |
| 科技面板 | 科技树 | 右侧滑出面板，科技项为带进度条卡片，点击升级 |
| 结算界面 | 成绩评级 | 居中大字评级(S/A/B/C)+统计数据+返回按钮 |

### 4.3 响应式设计
- 桌面优先：Canvas 区域自适应窗口尺寸
- 最小支持分辨率 1280×720
- 侧面板可折叠以适应小屏

### 4.4 动效指引
- 星图背景：缓慢漂移的星云粒子
- 飞船移动：沿航线平滑插值移动，尾部引擎光效
- 采矿动画：矿点脉动发光
- 战斗动画：光束闪烁+受击闪烁
- 事件触发：屏幕边缘红色/黄色警告光晕
- UI 交互：面板展开/收起过渡动画
