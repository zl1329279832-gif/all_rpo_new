# 卫星三维结构展示项目

基于 Vue 3 + TypeScript + Three.js 构建的高还原度卫星三维结构可视化展示系统。

## ✨ 功能特性

### 🛰️ 三维模型
- **卫星主体舱**：多层面板结构、螺栓细节、接口面板、金属材质
- **太阳能帆板**：阵列纹理、展开结构、铰链机构、驱动电机
- **天线系统**：高增益抛物面天线、S波段全向天线
- **推进系统**：主推进器、RCS姿态控制喷口
- **传感器系统**：星敏感器、太阳敏感器、IMU、GPS天线
- **散热系统**：散热片、热管、可展开散热器
- **支架系统**：太阳能帆板支架、天线桅杆、传感器安装座
- **线缆系统**：电力电缆、数据电缆、信号电缆、连接器
- **内部模块**：主板、蓄电池、星载计算机、电源控制器、存储器

### 🎮 交互功能
- **三种视图模式**：整体视图、爆炸拆解视图、内部结构视图
- **太阳翼展开动画**：一键播放太阳能帆板展开过程
- **部件交互**：点击任意部件查看功能说明和技术参数
- **相机控制**：左键旋转、右键平移、滚轮缩放
- **数据面板**：实时显示功率、姿态、温度、通信状态模拟数据

## 🎯 使用说明

### 视图切换

1. **整体视图**：显示卫星完整装配状态
2. **爆炸视图**：部件沿径向分离，展示各部件空间关系
3. **内部视图**：隐藏外部结构，展示内部模块布局

### 动画控制

- 点击「展开太阳翼」按钮播放太阳能帆板展开动画
- 点击「复位视角」将相机恢复到初始位置

### 部件交互

- 鼠标悬停在部件上时会高亮显示
- 点击部件弹出信息窗口，显示功能说明和技术参数
- 点击窗口外区域关闭信息窗口

### 数据面板

- **功率系统**：显示发电功率、电池电量、充电状态
- **姿态状态**：显示三轴角度、角速度、轨道高度
- **温度监控**：显示舱内温度、太阳能板温度、散热片温度
- **通信状态**：显示信号强度、下行速率、上行速率、连接状态

## 🔧 核心模块说明

### 材质管理器 (MaterialManager)

采用单例模式管理所有材质，避免重复创建，优化性能。支持金属、碳纤维、太阳能电池、发光等多种材质。

### 动画系统 (AnimationSystem)

基于 TWEEN.js 实现流畅的动画效果，支持：
- 太阳翼展开/收起动画
- 爆炸视图切换动画
- 内部视图切换动画
- 相机位姿动画

### 交互系统

- **Raycaster**：高效的射线检测，支持鼠标悬停和点击事件
- **LabelSystem**：动态创建部件信息标签，支持样式定制

### 资源释放 (ResourceDisposer)

统一管理几何体、材质、纹理的释放，防止内存泄漏。

## 📊 模拟数据

项目包含完整的模拟遥测数据生成器，模拟真实卫星运行状态：

| 数据类型 | 模拟内容 | 更新频率 |
|---------|---------|---------|
| 功率系统 | 发电功率、电池电量、充电状态 | 500ms |
| 姿态状态 | 三轴欧拉角、角速度、轨道高度 | 500ms |
| 温度监控 | 舱内温度、太阳能板温度、散热片温度 | 500ms |
| 通信状态 | 信号强度、上下行速率、连接状态 | 500ms |
