# 大型光伏电站三维运维展示系统

## 项目简介

本项目是一个基于 Vue 3 + TypeScript + Three.js 构建的大型光伏电站日常运维三维交互展示系统。通过三维可视化技术，直观展示光伏电站的设备布局、运行状态、故障告警和巡检路线，为运维人员提供沉浸式的监控和管理体验。

## 技术栈

- **前端框架**: Vue 3 + Composition API
- **类型系统**: TypeScript
- **三维引擎**: Three.js
- **图表库**: ECharts
- **动画库**: @tweenjs/tween.js
- **构建工具**: Vite
- **样式**: CSS3 + SCSS

## 功能特性

### 三维场景
- 🏗️ **设备建模**: 光伏板、逆变器、汇流箱、告警设备等精细化三维模型
- 🛣️ **场景布局**: 4个光伏方阵、巡检道路、地面环境完整呈现
- 🎮 **交互控制**: 鼠标缩放、旋转、平移，支持多角度观察

### 状态可视化
- 🟢 **正常运行**: 绿色标识，设备工作正常
- 🟡 **发电偏低**: 橙色标识，设备发电效率低于阈值
- 🔴 **温度异常**: 红色标识，设备温度过高
- ⚫ **设备离线**: 灰色标识，设备通信中断
- 🔵 **待维修**: 蓝色标识，设备需维护处理

### 交互功能
- 👆 **设备拾取**: 点击设备查看详细参数
- 🔍 **方阵定位**: 快速切换至指定光伏方阵
- 🔎 **状态筛选**: 按故障类型筛选显示设备
- 🛣️ **巡检模拟**: 自动巡检路线演示，支持镜头跟随
- 🎯 **设备定位**: 从告警列表快速定位故障设备

### 数据统计
- 📈 **发电量趋势**: 24小时发电量、辐照度、温度对比图
- 📊 **故障排行**: 各类故障数量统计排行
- 💚 **在线率统计**: 设备在线/离线比例环形图
- 🔧 **维护进度**: 维修工作进度可视化

### 性能优化
- ⚡ **实例化渲染**: 大量同类型设备使用 InstancedMesh 渲染
- 🗑️ **资源销毁**: 完整的资源释放机制，避免内存泄漏
- 🎨 **材质缓存**: 复用材质对象，减少显存占用
- 🔄 **数据缓冲**: 定时数据刷新，平衡性能与实时性

## 快速开始

### 环境要求

- Node.js >= 16.0.0
- npm >= 7.0.0 或 yarn >= 1.22.0

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

```bash
npm run build
```

- DOM 元素 + 3D 坐标投影

- 巡检路线可视化（虚线、路点标记）

### MockDataGenerator 数据模拟
- 700+ 设备模拟数据生成

- 发电量、辐照度等环境数据
- 故障告警事件生成

## 性能优化措施

1. **InstancedMesh**: 同类型设备使用实例化渲染，Draw Call 从数百降至个位数
2. **材质缓存**: 复用相同状态的材质对象，减少显存占用
3. **几何体合并**: 复杂模型合并为单个 BufferGeometry
4. **动态数据更新**: 仅更新变化的实例矩阵，避免重建
5. **资源释放**: 完整的 dispose 链路，确保组件卸载时无内存泄漏
6. **像素比限制**: 限制渲染像素比，避免高 DPI 设备性能损耗

## 开发说明

### 添加新设备类型

1. 在 `types/index.ts` 中扩展 `DeviceType` 枚举
2. 在 `ModelFactory.ts` 中添加对应模型生成方法
3. 在 `InstancedRenderer.ts` 中注册渲染分支
4. 更新状态图标和颜色映射

### 添加新的统计图表

1. 在 `components/charts/` 目录创建新图表组件
2. 在 `StatsPanel.vue` 中引入并布局
3. 在 `MockDataGenerator.ts` 中添加对应数据生成方法

## 常见问题

**Q: 场景加载缓慢怎么办？**
A: 首次加载需要生成700+设备模型，属正常现象。生产环境可使用预构建的模型文件。

**Q: 鼠标点击没反应？**
A: 请确保点击的是设备主体区域，地面和道路不可点击。可适当放大视角后再尝试。

**Q: 巡检时画面卡顿？**
A: 关闭"跟随镜头"选项可显著提升性能，相机会保持当前视角不动。
