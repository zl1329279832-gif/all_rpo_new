# 智慧水务泵站三维运行监控系统

基于 Vue 3 + TypeScript + Three.js + ECharts 构建的智慧水务泵站三维运行监控前端系统。

## 功能特性

### 核心功能

- **三维场景展示**：基于 Three.js 构建泵房、管道、水池、水泵、电控柜、阀门和传感器点位的三维模型
- **设备状态展示**：不同状态通过颜色、动画、标签和告警图标表现，包括运行、停机、告警、检修、离线、恢复中
- **交互操作**：支持场景旋转、缩放、平移，点击设备查看实时参数
- **告警管理**：按告警等级筛选（紧急/重要/一般/提示），支持告警处置全流程
- **区域切换**：进水区、泵房区、出水区三个区域快速切换，相机平滑移动
- **时间轴回放**：支持历史数据回放，水位、压力、流量、能耗、水泵状态、管道流动和告警图标联动变化
- **设备搜索定位**：支持按名称、ID、型号、厂家搜索设备，点击自动定位到三维场景
- **设备详情面板**：实时参数、维护记录、关联趋势三个标签页，展示完整设备信息

### 新增功能（v2.0）

1. **时间轴回放**
   - 支持 24 小时历史数据回放，每 5 分钟一帧
   - 水位、压力、流量、能耗、水泵状态、管道流动、告警图标联动变化
   - 实时/回放模式切换，播放速度调节（0.5x/1x/2x/4x）
   - 告警时间标记，快速定位告警发生时刻

2. **告警处置流程**
   - 支持告警等级、来源设备、触发时间展示
   - 告警状态流转：待确认 → 已确认 → 处置中 → 已恢复 → 已关闭
   - 处置记录管理，支持添加处置说明和附件
   - 点击告警自动定位到三维设备

3. **设备台账管理**
   - 完整设备信息展示：类型、型号、厂家、安装日期
   - 维护状态：故障次数、上次保养、下次保养
   - 维护记录：保养、维修、巡检三种类型，支持费用统计
   - 8 种场景模拟切换：正常运行、水位过高、压力异常、水泵停机、阀门故障、传感器离线、检修、恢复

4. **运维统计**
   - 设备运行统计：总数、在线率、故障率
   - 告警统计：各等级数量、各状态数量、处置率
   - 能耗流量统计：累计能耗、总流量、平均压力
   - 维护统计：维护次数、总费用、平均单次费用
   - 数据趋势图表：流量、能耗、在线率、告警趋势

### 性能优化

- **标签遮挡检测**：基于射线检测的标签可见度判断，被遮挡标签透明度降低
- **模型/材质复用**：几何体和材质全局缓存，相同类型设备共享资源
- **视锥剔除**：Three.js 内置视锥剔除，不可见对象不渲染
- **资源释放**：组件卸载时自动释放几何体、材质、纹理等 Three.js 资源
- **窗口自适应**：ResizeObserver 监听容器尺寸变化，自动调整相机和渲染器
- **动画优化**：requestAnimationFrame 驱动的统一动画循环，大量点位刷新不卡顿

## 使用说明

### 三维场景操作

- **旋转**：按住鼠标左键拖动
- **缩放**：鼠标滚轮滚动
- **平移**：按住鼠标右键拖动
- **查看设备**：点击三维设备模型，右侧弹出详情面板

### 告警处置流程

1. 进入「告警处置」页面
2. 查看告警列表，可按等级和状态筛选
3. 点击「确认」按钮确认告警
4. 点击「开始处置」添加处置记录
5. 问题解决后点击「标记恢复」
6. 最后点击「关闭告警」完成流程

### 时间轴回放

1. 在三维监控页面，点击时间轴上的「进入回放模式」
2. 拖动时间轴或点击播放按钮查看历史数据
3. 可调节播放速度（0.5x/1x/2x/4x）
4. 时间轴上的彩色标记表示告警发生时刻
5. 点击「退出回放」返回实时监控模式

### 设备搜索定位

1. 在三维监控页面顶部的搜索框输入关键词
2. 支持搜索设备名称、ID、型号、厂家、告警信息
3. 点击搜索结果自动定位到三维设备，相机会平滑飞行到目标位置
4. 设备会以青色发光效果高亮显示

### 场景模拟

1. 进入「设备台账」页面
2. 在顶部场景模拟栏选择不同场景
3. 三维场景中的设备状态和告警会相应变化
4. 支持 8 种场景：正常运行、水位过高、压力异常、水泵停机、阀门故障、传感器离线、检修、恢复

## 模拟数据说明

系统包含完整的模拟数据，涵盖以下内容：

### 设备数据（16 台设备）

- 4 台水泵：包含流量、扬程、效率、温度、振动、电流参数
- 4 个阀门：包含开度、压力、状态参数
- 4 个传感器：压力、流量、液位传感器
- 2 个电控柜：包含电压、电流、功率、频率参数
- 2 个水池：包含液位、容积参数

### 告警数据（8 条告警）

- 紧急告警：水泵过载、水位过高
- 重要告警：出口压力异常、阀门故障、传感器离线
- 一般告警：轴承温度偏高、流量异常
- 提示告警：设备检修提醒

### 回放数据

- 生成 24 小时回放数据，每 5 分钟一帧，共 288 帧
- 每帧包含：所有设备状态参数、水位、流量、能耗、告警信息
- 告警在时间轴上有彩色标记

### 场景数据（8 种场景）

| 场景 | 说明 |
|------|------|
| 正常运行 | 所有设备正常运行，无告警 |
| 水位过高 | 水池水位达到 5.2m，触发紧急告警 |
| 压力异常 | 出口压力降至 0.25MPa，触发重要告警 |
| 水泵停机 | 1# 水泵停机，状态变为灰色 |
| 阀门故障 | 出口阀门故障，无法正常开启 |
| 传感器离线 | 压力传感器通信中断，状态离线 |
| 设备检修 | 多台设备处于检修状态，黄色标识 |
| 故障恢复 | 故障设备逐步恢复正常运行 |

## 类型定义

核心类型定义在 `src/types/index.ts` 中：

- `DeviceData`：设备数据接口，包含基础信息、参数、告警、维护信息
- `AlarmInfo`：告警信息接口，包含等级、状态、处置记录
- `PlaybackFrame`：回放帧数据，包含某一时刻的所有设备和告警状态
- `PlaybackData`：回放数据集合，包含多帧时间序列数据
- `OperationStats`：运维统计数据接口
- `MaintenanceRecord`：维护记录接口
- `DisposalRecord`：告警处置记录接口
- 大量常量定义：状态颜色、标签、场景配置等

## 性能优化建议

### 三维渲染优化

1. **模型复用**：通过 `useModelFactory` 的几何体和材质缓存，相同类型设备共享资源
2. **视锥剔除**：Three.js 内置视锥剔除，确保只有视锥内的物体被渲染
3. **像素比率限制**：设置 `pixelRatio` 最大为 2，避免高分辨率屏幕性能损耗
4. **阴影优化**：仅对关键物体启用阴影，限制阴影贴图尺寸为 2048x2048

### 交互优化

1. **标签遮挡检测**：使用射线检测判断标签是否被遮挡，遮挡时降低透明度
2. **遮挡检测节流**：遮挡检测每 500ms 执行一次，避免过度计算
3. **相机阻尼**：OrbitControls 启用阻尼，让交互更流畅
4. **射线检测优化**：鼠标移动时仅检测第一个相交物体，提升性能

### 资源管理

1. **组件卸载清理**：`onBeforeUnmount` 中释放所有 Three.js 资源
2. **定时器清理**：所有 `setInterval` 都有对应的 `clearInterval`
3. **事件监听移除**：窗口 resize 事件、鼠标事件在组件卸载时移除
4. **ResizeObserver**：使用 ResizeObserver 替代 window.resize 事件，更精准高效

### 数据更新优化

1. **批量更新**：设备数据每 3 秒批量更新一次，避免频繁重绘
2. **按需更新**：只有变化的数据才会触发视图更新
3. **深监听优化**：使用 `{ deep: true }` 监听设备数组变化，确保子属性更新能被检测到
4. **计算属性缓存**：大量使用 `computed` 缓存派生状态，避免重复计算

## 常见问题

### Q: 三维场景加载慢怎么办？

A: 系统已做了模型复用和缓存优化，如果仍然卡顿，可以：
1. 降低浏览器窗口大小
2. 关闭其他占用 GPU 的程序
3. 检查显卡驱动是否最新

### Q: 标签显示不正常怎么办？

A: 标签系统会自动检测遮挡，如果标签闪烁或消失：
1. 尝试旋转视角让标签不被遮挡
2. 刷新页面重新初始化

### Q: 时间轴回放数据量太大？

A: 当前配置为 24 小时每 5 分钟一帧（288 帧），如果需要调整可以修改 `generatePlaybackData(hours, intervalMinutes)` 的参数。
