**处理流水线**:

```
持久化记录 → 去重检测 → OCR识别 → 目标准备 → 前置校验 → 重命名 → 归档 → 最终持久化
     ↓            ↓          ↓          ↓          ↓         ↓        ↓         ↓
_persist   _run_dedup   _run_ocr   _prepare    _validate   _rename   _archive  _persist
_document                                 _target   _pre_operation
```

**关键代码**:

```python
def _process_single(self, doc_info):
    self._persist_document(doc_info)              # 初始持久化
    
    if self._run_deduplication(doc_info):          # 去重检测
        self._persist_document(doc_info)
        return doc_info
    
    self._run_ocr(doc_info)                        # OCR识别
    
    if not self._prepare_target(doc_info):         # 准备目标路径
        self._persist_document(doc_info)
        return doc_info
    
    if not self._validate_pre_operation(doc_info):  # 前置校验（占用、权限）
        self._persist_document(doc_info)
        return doc_info
    
    if not self._rename_file(doc_info):            # 重命名文件
        self._persist_document(doc_info)
        return doc_info
    
    if not self._archive_file(doc_info):           # 归档文件
        self._persist_document(doc_info)
        return doc_info
    
    self._persist_document(doc_info)               # 最终持久化
    return doc_info
```

#### 2.2.3 批处理流程 [L468-L571](file:///e:/lingshi/all_rpo_new/r34/doc_auto_processor/executor.py#L468-L571)

1. **批次初始化**: `_init_batch()` 创建批次记录
2. **状态更新**: 设置为 `RUNNING`
3. **中断处理**: `InterruptHandler` 捕获 SIGINT/SIGTERM
4. **进度显示**: tqdm 进度条
5. **逐个处理**: 调用 `_process_single()`
6. **异常处理**: 每个文件独立 try-catch
7. **清单生成**: `manifest_gen.generate()`
8. **状态更新**: 根据结果设置最终状态

#### 2.2.4 批次状态机

```
PENDING → RUNNING → COMPLETED (全部成功)
              ↓        ↓
              ↓    → PARTIAL (部分失败)
              ↓        ↓
              ↓    → FAILED (全部失败)
              ↓
              → INTERRUPTED (用户中断)
              ↓
              → ROLLED_BACK (已回滚)
```

### 2.4 重复文件检测 - deduplicator.py

**文件**: [deduplicator.py](file:///e:/lingshi/all_rpo_new/r34/doc_auto_processor/deduplicator.py)

#### 2.4.1 哈希计算

**完整哈希** [L21-L50](file:///e:/lingshi/all_rpo_new/r34/doc_auto_processor/deduplicator.py#L21-L50):
- 64MB 分块读取，内存友好
- 支持 `max_retries` 重试

**快速哈希** [L52-L76](file:///e:/lingshi/all_rpo_new/r34/doc_auto_processor/deduplicator.py#L52-L76):
- 算法: `SHA256(文件大小 + 文件头部1MB + 文件尾部1MB)`
- 适合大文件场景，存在哈希碰撞风险

#### 2.4.2 去重策略

| 策略 | 行为 | 适用场景 |
|------|------|---------|
| **SKIP** | 跳过重复文件，标记为 DEDUPLICATED | 严格去重场景 |
| **KEEP_COPY** | 重命名添加 `_copy` 后缀，保留所有文件 | 需要保留所有版本 |
| **MOVE_TO_DUPLICATE_AREA** | 移动到 `_duplicates` 目录，重命名为 `时间戳_哈希前缀_原名` | 归档整理场景 |

#### 2.4.3 检测流程 [L123-L145](file:///e:/lingshi/all_rpo_new/r34/doc_auto_processor/deduplicator.py#L123-L145)

```python
def check_duplicate(self, doc_info, max_retries=3):
    file_hash = self.calculate_hash(doc_info)
    if not file_hash:
        return False, None
    
    # 1. 检查批次内重复（内存缓存）
    if file_hash in self._seen_hashes:
        return True, file_hash
    
    # 2. 检查历史重复（数据库查询）
    existing_doc = self._db.find_document_by_hash(file_hash)
    if existing_doc:
        return True, file_hash
    
    self._seen_hashes.add(file_hash)
    return False, None
```

### 2.7 回滚管理 - rollback.py

**文件**: [rollback.py](file:///e:/lingshi/all_rpo_new/r34/doc_auto_processor/rollback.py)

#### 2.7.1 冲突检测 [L43-L76](file:///e:/lingshi/all_rpo_new/r34/doc_auto_processor/rollback.py#L43-L76)

**核心逻辑**: 回滚前对目标位置进行 SHA-256 哈希校验

```python
def _check_conflict(self, doc, source_path):
    if source_path.exists():
        existing_hash = hashlib.sha256(source_path.read_bytes()).hexdigest()
        target_hash = doc.metadata.sha256_hash
        
        if existing_hash == target_hash:
            return {
                "type": "same_content",      # 相同内容，自动跳过
                "message": "目标位置已存在相同内容的文件，将跳过"
            }
        else:
            return {
                "type": "different_content", # 不同内容，禁止覆盖
                "message": "目标位置已存在不同内容的文件，禁止覆盖"
            }
    return None
```

#### 2.7.2 回滚流程

```
1. 验证批次存在且未回滚
2. 获取批次中所有成功处理的文档
3. 逐个检查冲突 → 跳过/禁止
4. 无冲突文件执行恢复（复制+删除）
5. 更新数据库状态为 ROLLED_BACK
6. 清理空目录
7. 生成回滚报告
```

```python
def _cleanup_empty_dirs(self, base_dir):
```

```python
def calculate_sha256(file_path, max_retries=3):
    sha256 = hashlib.sha256()
    with open(file_path, "rb") as f:
```

### 5.6 并发问题

#### ❌ P1: 多进程并发处理风险

**问题描述**:
系统设计为单进程运行，但缺少并发防护机制:

1. **数据库层面**:
   - SQLite 默认单进程写入
   - 多进程同时写入会抛出 `database is locked` 异常
   - 系统没有配置 `timeout` 参数，也没有重试机制

2. **文件层面**:
   - 多个进程处理同一源目录可能导致重复处理
   - 回滚和处理同时运行可能导致文件丢失

3. **缺少进程锁**:
   - 没有 pid 文件或锁机制防止多实例运行

**风险**:
1. 数据库损坏
2. 文件状态混乱
3. 重复处理浪费资源

**影响级别**: 高  
**触发场景**: 计划任务重复执行、用户误操作

```python
def acquire_process_lock(lock_path: Path) -> bool:
    """获取进程独占锁，防止多实例运行"""
    import fcntl  # Windows 需要使用其他方式
    lock_file = open(lock_path, 'w')
    try:
        fcntl.flock(lock_file, fcntl.LOCK_EX | fcntl.LOCK_NB)
        lock_file.write(str(os.getpid()))
        return True
    except IOError:
        return False
```
