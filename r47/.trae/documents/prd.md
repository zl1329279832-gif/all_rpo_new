## 1. 产品概述

商队贸易策略游戏——玩家扮演古代丝路商人，在多座古城之间规划路线，低价购入货物、高价售出，同时应对天气、盗匪、路费、仓储限制与城市价格波动。核心体验为**路线规划 + 风险管理 + 经济博弈**。

- 目标用户：策略/经营类游戏爱好者，偏好轻度 Roguelike 体验的单机玩家
- 市场价值：以低门槛浏览器游戏形态，提供具备重玩性的贸易策略体验

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 |
|------|------|
| 商队领袖 | 玩家唯一身份，拥有资金、声望、护卫等级等属性 |

### 2.2 功能模块

1. **地图主界面**：丝路地图、城市节点、商队位置、路线选择
2. **交易面板**：城市集市买卖、价格展示、库存查看
3. **商队状态栏**：资金、负重、护卫、声望、当前城市
4. **事件弹窗**：随机事件触发与选择
5. **任务面板**：委托任务列表、任务进度
6. **存档/读档**：本地存档管理

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 地图主界面 | 丝路地图 | Canvas 渲染 6 座城市节点与路线，商队图标沿路线移动动画 |
| 地图主界面 | 商队状态栏 | 顶部 HUD 显示资金、负重比、护卫等级、声望、天数 |
| 地图主界面 | 事件弹窗 | 移动途中触发天气/盗匪/商人偶遇等事件，提供 2-3 选项 |
| 交易面板 | 城市集市 | 展示 8 类商品当前买入/卖出价，支持批量交易 |
| 交易面板 | 库存管理 | 当前携带货物列表（重量、保质期、购入价），可丢弃 |
| 任务面板 | 委托列表 | 2 条完整任务线的任务节点与进度追踪 |
| 存档面板 | 存档管理 | 3 个存档槽位，支持保存/读取/删除 |

## 3. 核心流程

玩家从起始城市出发，在城市集市购买货物 → 选择下一座城市出发 → 途中遭遇随机事件并决策 → 到达目标城市后卖出货物/接取任务 → 循环。资金归零或声望过低则游戏失败；完成主线任务线或积累目标资金则胜利。

```mermaid
flowchart TD
    "城市驻留" --> "集市交易"
    "集市交易" --> "选择路线"
    "选择路线" --> "旅途事件"
    "旅途事件" --> "事件决策"
    "事件决策" --> "到达目标城市"
    "到达目标城市" --> "价格波动结算"
    "价格波动结算" --> "城市驻留"
    "事件决策" --> "游戏失败"
    "城市驻留" --> "查看任务"
    "查看任务" --> "集市交易"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：琥珀金 (#D4A017) + 深沙棕 (#3E2723)，辅以沙黄 (#F5E6C8) 底色
- 按钮风格：圆角木质按钮，hover 时发光描边
- 字体：标题用 "Cinzel" (衬线展示字体)，正文用 "Noto Sans SC"
- 布局风格：顶部 HUD 状态栏 + 中央 Canvas 地图 + 右侧/底部信息面板叠加
- 图标风格：手绘丝路风格 SVG 图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 地图主界面 | 丝路地图 | Canvas 全屏，城市为金色圆点+名称标签，路线为虚线，商队为骆驼图标 |
| 地图主界面 | 商队状态栏 | 顶部半透明深色条，金币/背包/盾牌/星星图标+数值 |
| 交易面板 | 城市集市 | 右侧滑入面板，商品列表含名称/重量/单价/保质期，买入/卖出按钮 |
| 事件弹窗 | 事件卡片 | 居中弹出卡片，事件插画+描述+选项按钮，背景半透明遮罩 |
| 任务面板 | 委托列表 | 左侧抽屉面板，任务线进度条+任务描述+奖励预览 |

### 4.3 响应式

- 桌面优先设计，Canvas 地图占据主要空间
- 窗口缩放时 Canvas 自适应分辨率
- 面板采用绝对定位叠加，不挤压地图

### 4.4 3D 场景指导

不适用——本项目使用 2D Canvas / PixiJS 渲染。
