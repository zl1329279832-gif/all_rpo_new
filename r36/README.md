# 连锁餐饮数据分析平台

面向连锁餐饮管理人员的 Streamlit 数据分析平台，提供全方位的经营数据洞察与决策支持。

## 功能特性

### 🆕 新增功能特性

#### 🔍 增强型数据校验
- **多维度关联校验**：检查主键重复、关联失败、异常金额、非法日期、退款订单不匹配
- **7类数据质量问题**：缺失字段、类型不匹配、重复主键、负数金额、异常大值、无效日期、关联孤儿
- **质量评分体系**：综合评分（0-100），按严重程度分类统计
- **问题清单展示**：按严重程度（🔴严重/🟡警告/🔵提示）过滤，显示影响行数和示例值
- **异常数据测试集**：包含500条订单的异常测试数据，用于验证校验功能

#### 🚨 智能预警系统
- **4类核心预警**：
  - 📉 营业额下降预警（周同比下降超过阈值）
  - 💰 退款率过高预警（超过安全阈值）
  - 📊 毛利率偏低预警（低于行业标准）
  - 💹 客单价异常波动预警（超过波动阈值）
- **门店健康评分**：综合毛利率、退款率、营收趋势计算0-100分
- **预警触发原因**：自动分析并展示触发预警的具体原因
- **可配置阈值**：支持自定义各预警类型的触发阈值

#### 📊 新增经营分析
- **门店排名对比**：按营业额、毛利、订单数、客单价、毛利率5个维度排名
- **午晚餐表现分析**：早餐/午餐/下午茶/晚餐/夜宵五时段经营指标对比
- **菜品毛利贡献**：核心利润菜品（50%）、重要利润菜品（80%）、补充利润菜品（95%）、低贡献菜品分层
- **会员复购周期**：高频（≤3天）、较高频（3-7天）、中频（7-14天）、较低频（14-30天）、低频（>30天）
- **活动投入产出比**：ROI计算，按优秀/良好/一般/亏损分级
- **原料成本波动**：变异系数分析，按剧烈/较大/轻微/稳定分级
- **退款原因分布**：按退款次数和金额双重维度统计

#### 🎛️ 多维度筛选
- **7个筛选维度**：日期范围、城市、区域、门店、会员等级、菜品分类、活动
- **全选/取消全选**：一键操作
- **筛选条件概览**：实时显示当前选中条件
- **重置筛选**：一键恢复默认
- **空数据提示**：筛选结果为空时友好提示

#### ⚡ 性能优化
- **12个计算密集型函数**添加 Streamlit `@st.cache_data` 缓存
- **TTL智能配置**：
  - 数据校验：3600秒
  - RFM计算：600秒
  - 常规指标：300秒
- **避免重复计算**：相同输入自动复用缓存结果

#### 📋 优化报告导出
- **数据质量章节**：质量评分、问题总数、严重/警告问题数、完整问题清单
- **预警信息章节**：整体健康评分、预警总数、各类型预警统计、预警清单
- **核心指标章节**：KPI指标卡片、同比环比分析
- **格式优化**：按问题严重程度自动标记颜色，涨跌自动着色
- **可选章节**：支持是否包含数据质量和预警信息

### 核心算法

1. **RFM 模型**：基于最近购买(Recency)、购买频率(Frequency)、购买金额(Monetary)的客户价值分层
2. **异常检测**：
   - IQR（四分位距）法：识别偏离1.5倍四分位距的异常值
   - Z-score 法：识别偏离均值3倍标准差的异常值
3. **关联规则**：基于支持度计算的菜品组合挖掘
4. **统计检验**：使用 SciPy 进行显著性检验
5. **预警检测算法**（新增）：
   - **营业额下降预警**：周同比对比，支持自定义阈值
   - **退款率预警**：计算退款订单占比，超过阈值触发
   - **毛利率预警**：计算综合毛利率，低于阈值触发
   - **客单价波动预警**：基于变异系数的波动检测
6. **门店健康评分**（新增）：
   - 综合毛利率（权重40%）
   - 退款率（权重30%）
   - 营收趋势（权重20%）
   - 订单量（权重10%）
7. **数据质量评估**（新增）：
   - 7类问题检测，按严重程度加权扣分
   - 综合评分0-100分
8. **毛利贡献分析**（新增）：
   - 累计贡献度分层（50%/80%/95%）
   - 帕累托法则（80/20）应用

### 新增数据质量校验规则（共7类）

| 校验类型 | 说明 | 严重程度 |
|----------|------|----------|
| 缺失字段 | Schema定义的必填字段不存在 | 🔴 严重 |
| 重复主键 | 主键字段存在重复值 | 🔴 严重 |
| 负数金额 | 金额字段为负值 | 🔴 严重 |
| 退款不匹配 | 退款订单号在订单表中不存在 | 🔴 严重 |
| 关联失败 | 外键值在关联表中不存在 | 🟡 警告 |
| 异常大值 | 金额超过99分位×3 | 🟡 警告 |
| 无效日期 | 日期字段无法解析 | 🟡 警告 |
| 类型不匹配 | 字段类型与定义不符 | 🟡 警告 |
| 数据缺失 | 字段值为空 | 🔵 提示 |

1. **数据准备**：使用示例数据或上传自定义 CSV 文件
2. **数据校验**：在「数据上传与校验」页面检查数据质量，查看问题清单

4. **查看结果**：在「🔍 数据质量问题清单」标签页验证以下异常是否被正确识别：

   - ✅ 异常大值（3个）
   - ✅ 无效日期（2个）
   - ✅ 关联失败（4个）
   - ✅ 退款不匹配（3个）
   - ✅ 缺失值（约10%）
5. **对比测试**：使用 `sample_data/` 目录下的正常数据，验证高质量数据可顺利通过校验

## 核心模块 API

### config/schemas.py

定义所有数据表的字段类型和业务规则：

```python
DATA_SCHEMAS = {
    "stores": {"store_id": "string", "store_name": "string", ...},
    "dishes": {"dish_id": "string", "dish_name": "string", ...},
    ...
}
```

### core/ingestion.py

- `load_csv_files(files)`: 加载多份 CSV 文件
- `load_sample_data()`: 加载内置示例数据
- `detect_file_type(filename)`: 自动识别文件类型

### core/validation.py

- `validate_all_datasets(datasets)`: 校验所有数据集
- `check_missing_values(df)`: 检查缺失值
- 返回 `ValidationReport` 数据类，包含校验详情

### core/transform.py

- `clean_data(df)`: 数据清洗与格式化
- `merge_orders_with_details(orders, items)`: 关联订单与明细
- `filter_by_date_and_store(df, start_date, end_date, stores)`: 联动筛选

### core/metrics.py

- `calculate_kpi_metrics(df)`: 计算核心 KPI 指标
- `calculate_rfm(df)`: RFM 分析与客户分层
- `detect_anomalous_stores(df, method)`: 异常门店识别
- `analyze_dish_combinations(df)`: 菜品组合关联分析

### core/visualization.py

提供 13+ 种 Plotly 图表函数：
- `plot_revenue_trend()`: 营收趋势图
- `plot_store_comparison()`: 门店对比图
- `plot_rfm_3d_scatter()`: RFM 3D散点图
- `plot_profit_matrix()`: 利润矩阵四象限
- `plot_anomaly_radar()`: 异常雷达图

### core/export.py

- `generate_excel_report(analysis_results, output_path)`: 生成 Excel 报告
- `generate_html_report(analysis_results, output_path)`: 生成 HTML 报告

3. 使用 `st.session_state` 共享数据和筛选条件
4. 参考现有页面的结构实现分析逻辑

### 扩展数据校验规则

在 `config/schemas.py` 中添加新的 schema 定义，然后在 `core/validation.py` 中实现对应的校验函数。

### 自定义图表样式

所有图表样式通过 `core/visualization.py` 中的 `_apply_chart_style()` 函数统一管理，支持：
- 商务蓝(#1976D2)与暖橙(#FF9800)配色
- 统一字体和边距
- 响应式布局

## 常见问题

**Q: 如何使用自己的业务数据？**

A: 确保数据格式与 schema 定义一致，在「数据上传与校验」页面上传对应的 CSV 文件即可。

**Q: 报告导出失败怎么办？**

A: 检查 `exports/` 目录是否有写入权限，确保已安装 `openpyxl` 和 `xlsxwriter` 包。

**Q: 可以自定义分析指标吗？**

A: 可以在 `core/metrics.py` 中添加新的指标计算函数，然后在对应页面调用。
