## 1. 产品概述

本产品是面向连锁餐饮管理人员的 Streamlit 数据分析平台，提供数据上传、清洗、多维度分析与报告导出的一站式解决方案。通过整合门店、菜品、订单、会员、优惠活动、退款、营业时段与原料成本等多源数据，帮助管理层快速洞察经营状况，优化决策。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 餐饮管理人员 | 本地部署无需登录 | 数据上传、全量分析、报告导出 |
| 数据分析师 | 本地部署无需登录 | 深度数据探索、指标自定义 |

### 2.2 功能模块

1. **数据上传与校验页**: 多 CSV 文件上传、字段合法性检查、缺失数据提示
2. **经营概览页**: 营业额/毛利核心指标、趋势分析、门店联动筛选
3. **菜品分析页**: 菜品销售排行、组合分析、毛利贡献度
4. **会员与复购页**: 客单价分析、复购分层、会员价值评估
5. **活动与退款页**: 优惠活动效果对比、退款原因分析
6. **异常检测页**: 异常门店识别、营业时段分析、原料成本监控
7. **报告导出页**: 生成可下载的 Excel 或 HTML 分析报告

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据上传与校验 | 文件上传模块 | 支持多文件拖拽上传，识别 8 类业务数据表 |
| 数据上传与校验 | 数据校验模块 | 字段类型检查、缺失值统计、异常值标记、数据质量评分 |
| 经营概览 | KPI 指标卡 | 展示营业额、毛利、客单价、订单数等核心指标及同比环比 |
| 经营概览 | 趋势图表 | 营业额/毛利时间序列、门店对比柱状图、热力图 |
| 菜品分析 | 销售排行 | 菜品销量/销售额/毛利排行，支持按门店/时间段筛选 |
| 菜品分析 | 组合分析 | 菜品关联规则分析、热销组合识别 |
| 会员分析 | 复购分层 | RFM 模型、会员价值分群、复购率趋势 |
| 活动分析 | 效果对比 | 活动前后指标对比、ROI 分析、优惠券核销率 |
| 异常检测 | 门店识别 | 基于统计方法识别异常经营门店、成本异常预警 |
| 报告导出 | 报告生成 | 一键生成 Excel/HTML 报告，支持自定义章节 |

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：专业商务蓝（#1976D2）与暖橙（#FF9800）搭配，体现餐饮行业活力与数据分析专业性
- 配色方案：深蓝背景 + 白色卡片 + 彩色图表系列
- 字体：Inter 无衬线字体，层次分明的标题与正文比例
- 布局：侧边栏导航 + 卡片式内容区，信息密度适中
- 交互：悬停高亮、平滑过渡动画、数据加载骨架屏

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 数据上传与校验 | 文件上传区 | 大尺寸拖拽区域、文件列表、校验进度条、错误提示卡片 |
| 经营概览 | KPI 指标区 | 大号数字卡片、趋势箭头、对比标签、颜色编码 |
| 经营概览 | 图表区 | 交互式 Plotly 图表、时间范围选择器、门店筛选器 |
| 菜品分析 | 排行表 | 带条形图的数据表、分类筛选、排序切换 |
| 会员分析 | 分层图表 | 散点图、漏斗图、人群画像卡片 |
| 异常检测 | 预警卡片 | 红黄绿状态指示器、异常原因标签、建议措施 |
| 报告导出 | 配置面板 | 复选框章节选择、格式切换、进度条、下载按钮 |

### 4.3 响应式设计

- 桌面端优先设计，侧边栏固定宽度 280px
- 平板端自动折叠侧边栏为图标模式
- 移动端单列布局，图表自适应宽度
- 表格支持横向滚动，关键列冻结
